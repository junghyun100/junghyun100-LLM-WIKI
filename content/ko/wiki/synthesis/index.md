# 합성/분석 (Synthesis)

여러 페이지와 소스를 함께 읽고 종합 결론을 만드는 섹션입니다.

---

## 현재 상태

아직 실제 합성 문서는 없습니다.

다만 아래와 같은 주제는 이 섹션에 잘 맞습니다.

- 여러 개념 문서를 하나의 실행 가이드로 묶기
- 서로 다른 소스의 공통 패턴과 차이 정리
- 시계열 변화나 의사결정 흐름 요약

## 첫 합성 문서 후보

- 프로토콜 관련 개념 문서 전체 요약
- 운영 모드별 차이와 실무 적용법
- 스펙 준비도와 워크플로 상태 머신의 관계 정리
